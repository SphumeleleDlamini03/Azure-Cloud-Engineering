# Azure-Cloud-Engineering
Welcome to My Cloud engineering journey!

This repository documents the development of practical cloud engineering capabilities through structured, hands-on sprints focused on Microsoft Azure, Infrastructure as Code, automation, DevOps, and cloud operations.

The objective is to move beyond theoretical knowledge by designing, implementing, documenting, and validating real cloud infrastructure and engineering workflows.

## Objectives

By completing this roadmap, I aim to develop and demonstrate practical skills across the following areas:

- Terraform Foundations - Sprint 1 
- Terraform Modules & Git Workflow - sprint 2
- Terraform Automation with GitHub Actions - Sprint 3
- Azure DevOps Pipelines & Approvals - Sprint 4
- PowerShell for Cloud Operations - Sprint 5
- Python for Cloud Automation - Sprint 6
- Docker & Azure Container Apps - - Sprint 7
- Azure Cloud Security - - Sprint 8

The roadmap is divided into sprints, with each sprint building on what I learned in the previous one. The goal is to start with the basics and gradually build the skills needed to design, automate, secure, and manage cloud infrastructure.

## Engineering Approach

Each sprint follows:

Learn → Design → Build → Validate → Document

The focus is on producing working implementations and documenting the decisions, challenges, and lessons learned along the way.
